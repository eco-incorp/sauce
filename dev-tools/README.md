# Sauce example projects

To build an application with Sauce, install the SDK:

```sh
pnpm add @eco-incorp/sauce
```

Follow the [quick start](../docs/guides/quick-start.md)
and [executable examples](../docs/examples/README.md)
for compiling programs and constructing Eco intents in your own project. You can also open the installed manual at `node_modules/@eco-incorp/sauce/docs/README.md`.

The `sauce-dev-tools` scaffold contains older local deployment and execution scripts. Those scripts
target an earlier EVM contract interface and are incompatible with current Kitchen/Pot deployments.
Use the SDK's [execution guides](../docs/guides/compiling.md)
for current programs.
